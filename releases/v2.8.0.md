# FieldScribe v2.8.0 - BOLD5 / BCDM export

BOLD has retired the old v3.0 four-sheet submission template. FieldScribe's BOLD
export now follows its replacement: the **BOLD5 BCDM** (Barcode Core Data Model)
**single-sheet** template.

## Changed

The BOLD export is now **one `Submissions` sheet** with the **50 BCDM columns**
in BOLD's exact order, instead of the four separate sheets (Voucher Info /
Taxonomy / Specimen Details / Collection Data) of the retired v3.0 template.

Everything FieldScribe already captures maps straight across. The value mapping
to BOLD's controlled vocabularies is:

- **Sex** -> `Male` / `female` / `hermaphrodite` (BCDM's exact terms). No
  "undetermined" term exists, so an unknown sex is left blank.
- **Life stage** -> `Adult` / `Immature` / `Juvenile` / `Pupa`. `Immature` is
  BOLD's catch-all, so larva, egg, embryo and zygote all fold into it.
- **Dates** are ISO `YYYY-MM-DD` (what BCDM wants), not the old `DD-MMM-YYYY`.
- **Tissue type** is free text - BCDM has no controlled vocabulary for it.

BOLD fuzzy-matches recommended-vocabulary values on import and keeps your
verbatim entry in a separate field, so small differences are tolerated.

The export button is relabelled **BOLD5 / BCDM (Excel)**, and the file is named
`fieldscribe-BOLD-BCDM-<date>.xlsx`. The offline single-CSV fallback still works
the same way, now with the 50 BCDM columns.

## Not yet captured

Several BCDM columns have no field in FieldScribe yet and export blank for you to
fill on BOLD (or we add fields later if useful): museum ID, collection code,
funding source, subfamily, tribe, subspecies, identified-by, identification
method, voucher type, associated taxa/specimens, and a few notes/accuracy fields.

## Verification

Column names and vocabularies were taken from the official
[`boldsystems-central/BCDM`](https://github.com/boldsystems-central/BCDM)
repository (`field_definitions.tsv`) and the current single-sheet template, not
from guesswork - the submission value for Sex really is the words
`Male`/`female`/`hermaphrodite`, not the `M`/`F`/`H`/`U` display codes shown on
BOLD's controlled-vocabularies web page.
