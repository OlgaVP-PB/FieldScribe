# FieldScribe v2.3.1 - Save field data without the lab fields

A field-usability fix on the eDNA path.

## Fixed

Saving an eDNA sample in the field was blocked until the desk/lab fields were
also filled - Strain, Scientific name, tax_id and Project. Those are meant to be
added later, not on site.

Save now enforces only the **on-site** mandatory fields (Sample ID, date,
country, GPS, the ENVO context, depth/elevation). The desk/lab fields are
deferred, and the save confirmation lists what is still needed before export.

Export gains a matching safeguard: if any eDNA sample is still missing required
fields, it shows a warning listing which samples and fields, and lets you either
go back and complete them or export anyway. It never silently ships an incomplete
sample, and never blocks you.
