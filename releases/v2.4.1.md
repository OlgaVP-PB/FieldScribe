# FieldScribe v2.4.1 - Citation & DOI

FieldScribe is now deposited on **SciLifeLab Serve** with a citable DOI, and this
release surfaces it.

## Added

- **Citation line in the app footer** with the concept DOI, so anyone using the
  app can cite it.
- **`CITATION.cff`** in the repository, which makes GitHub show a "Cite this
  repository" button (APA / BibTeX) generated from the DOI and author metadata.

## How to cite

> Vinnere Pettersson, O. (2026). *FieldScribe: Field sample metadata, made easy.*
> SciLifeLab Serve. https://doi.org/10.82595/scilifelab.jn54y-gez42

- Concept DOI (always resolves to the latest version): `10.82595/scilifelab.jn54y-gez42`
- Version 1 DOI: `10.82595/scilifelab.nvjed-dy092`

Hosted app: https://fieldscribe.serve.scilifelab.se · Serve record:
https://serve.scilifelab.se/records/4967/

## Note

This release keeps FieldScribe focused on genomics submissions (its exports use
fixed, validated controlled vocabularies). Support for general lab-use samples
(other omics, morphology, vouchering) with validation-free outputs is planned for
a later release, once required fields have been gathered from the relevant
SciLifeLab platforms.
