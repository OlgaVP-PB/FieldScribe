# FieldScribe v2.3.0 - Manifest export to Excel and CSV

v2.3.0 adds Excel output to the specimen-manifest export, on feedback from Felix
Shaw (Earlham Institute, COPO), who noted that COPO ingests `.xlsx`. Exporting
both formats smooths the path from a field sheet into COPO / the ERGA manifest.

## What changed

- The **ERGA/DToL** and **PopGenomics** manifest exports now produce a **`.xlsx`
  file alongside the CSV**. Each workbook is a single sheet with the identical
  91-column v2.5.1 header and one row per tube, so it drops into COPO the same
  way the CSV does.
- Excel is generated with the SheetJS library already bundled for the BOLD
  export, so there is no new dependency.
- Offline, the CSV is still written and a short note explains that the Excel file
  needs a connection (the library loads from a CDN).
- The export button now reads "ERGA manifest (CSV + Excel)", and the confirmation
  message reports which formats were saved.

## Still open (not in this release)

- **Validation parity.** What FieldScribe treats as valid and what COPO enforces
  are not yet guaranteed to match. Aligning them, or sharing a validation engine,
  is the natural next step and a candidate for collaboration.
- **Hi-C** as a formal `PURPOSE_OF_SPECIMEN` term remains a question for the ERGA
  samples working group.
