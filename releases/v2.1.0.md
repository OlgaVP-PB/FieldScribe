# FieldScribe v2.1.0 — eDNA / environmental path + Serve hosting

v2.1.0 adds the environmental-sampling side to FieldScribe and packages the app
for hosting on SciLifeLab Serve.

## eDNA / environmental path — 10 ENA checklists
A new **eDNA / environmental** path captures environmental-sample metadata and
exports an **ENA-ready TSV** per checklist. Ten environments are supported, each
mapped to its live ENA checklist with exact field labels, units, mandatory flags
and controlled vocabularies:

- GSC MIxS environmental: **Water** (ERC000024), **Soil** (ERC000022),
  **Sediment** (ERC000021), **Air** (ERC000012), **Microbial biofilm**
  (ERC000019), **Plant associated** (ERC000020), **Wastewater sludge**
  (ERC000023), **Miscellaneous environment** (ERC000025)
- Specialised: **Marine microalgae** (ERC000043, culture/strain), **Ancient DNA
  / sedaDNA** (ERC000059, excavation + dating)

Each field is tagged **on-site** or **desk/lab**, so the field form shows only
what must be recorded in the field (GPS, date, depth/elevation, the ENVO context
triple, and the field-only essentials — filter/volume/storage or mass/device),
and defers the metagenome ID, project, and sequencing fields. ENVO fields offer
suggestion lists; the metagenome tax_id has a lookup. Export produces one
`Checklist / field / #units / samples` TSV per environment.

## Hosting on SciLifeLab Serve
Added `Dockerfile` (nginx-unprivileged, runs as uid 1000, port 8080),
`nginx.conf`, `start-script.sh`, `.dockerignore`, and `SERVE_DEPLOY.md`. The app
is fully client-side (LocalStorage) with no backend, so Serve storage = None.

## Wording
The specimen "Save session" button is now "Save specimen", with a note that data
is saved in the browser on the device (nothing sent to a server).

## Notes
Specimen paths (ERGA/DToL, PopGenomics, BOLD) are unchanged. eDNA configs live in
`schema/mixs-*.json`, generated from the live ENA checklists — a future ENA
update is a re-extract, not a rewrite.
