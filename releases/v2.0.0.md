# FieldScribe v2.0.0 — Modular, manifest-native

FieldScribe v2.0.0 turns a single flat form into a **modular field-metadata tool
that stays simple in the field** but exports straight into the genomics
manifests — no wrestling a 90-column spreadsheet or reading a 35-page SOP.

## Why this is a major version
The CSV export now uses **canonical ENA / ERGA column names and controlled
vocabularies** (ERGA Sample Manifest v2.5.1, 91 columns). Field CSVs merge into
the manifest by stacking rows and joining on `COLLECTOR_SAMPLE_ID` — no manual
re-mapping. Because the output schema changed, this is a breaking change and so a
MAJOR bump.

## What's new
- **Pick a path on open** — *Specimen sampling* (active) and *eDNA / environmental*
  (coming next).
- **Unified individuals → tubes model.** A shared species + collection-event
  block, then 1..N individuals (each its own `SPECIMEN_ID`, sex, life stage),
  each split into 1..N tubes (tube ID, collector sample ID, organism part,
  purpose). A single reference-genome specimen = one individual with many tubes;
  a population = many individuals with one tube each.
- **Purpose-routed export, one row per tube.** `REFERENCE_GENOME` (incl. Hi-C)
  rows → **ERGA / DToL** manifest CSV; all other purposes → **BGE-ERGA
  PopGenomics** manifest CSV (adapted by José Melo-Ferreira et al.). Identical
  91-column header; only the files you need download.
- **BOLD / iBOL export** — a four-sheet Excel workbook (Voucher Info, Taxonomy,
  Specimen Details, Collection Data), one record per tube.
- **Taxonomy auto-lookup** — typing a scientific name fetches the NCBI `TAXON_ID`
  (+ common name) from ENA and the ranked lineage (phylum → genus) from GBIF,
  filling only empty fields.
- **Field-friendly input** — type locations with slashes ("Sweden / Uppsala /
  Fyrisån"; converted to the manifest's pipes on export); camera barcode scanner;
  a collection / institution name field for zoo / garden / culture specimens;
  transect and original-location toggles; fully offline (LocalStorage).

## Schema basis
ERGA Sample Manifest v2.5.1 (91 columns), embedded as a swappable config
(`schema/manifest-2.5.1.json`) so a future manifest release is a config update,
not a rewrite. BOLD mapping in `schema/bold-template-3.0.json`.

## Known open question
`PURPOSE_OF_SPECIMEN` has no Hi-C term yet; the app offers a UI-only "Hi-C"
choice that exports as `REFERENCE_GENOME` with a note in `OTHER_INFORMATION`.

## Next

  volume filtered, preservation buffer).
- Auto-fill higher ranks already wired; later: barcoding/biobanking/voucher
