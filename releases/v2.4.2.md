# FieldScribe v2.4.2 - In-app help (camera + About)

Since FieldScribe is now hosted on Serve, users never see the README - so the
help people were asking for now lives inside the app.

## Added

- **Camera help built into the scanner.** Testers kept asking how to turn the
  camera on. Now, if the scanner can't start, it shows a clear panel explaining
  how to allow camera access, with separate steps for **iPhone / Safari** and
  **Android / Chrome**, and a **Try again** button. Every time the scanner opens
  it also reminds people to tap **Allow** when the browser asks.
- **"About & help" on the first page.** A collapsible panel at the top of the
  path picker covering the essentials that used to live only in the README: what
  FieldScribe is, how it works, offline use, that data is stored on the device
  (back up / export to keep it safe), camera scanning, and - importantly for the
  testing phase - **how to send feedback** (email and GitHub Issues).

## Why

On SciLifeLab Serve the app opens straight to a URL with no repository page in
sight, so first-time and non-technical users had no on-ramp. These two additions
put the orientation and the most-asked-for help where people actually are.
