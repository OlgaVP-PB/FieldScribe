# FieldScribe v2.3.2 - Clearer offline instructions

A small wording change, no functional change.

## Changed

The footer install tip and the README now state the offline rule plainly: **open
the app once with a connection to enable offline use**, after which it works with
no signal in the field.

This is normal Progressive Web App behaviour. A service worker can only save a
copy of the app on a load that has a connection, so the very first launch must be
online. Opening a freshly added home-screen icon straight into airplane mode
leaves nothing cached; opening it once online first solves it for good.
